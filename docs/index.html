PROMPTS THAT WORK FOR PROJECT 2:

⚡
Always end every prompt with: "Give me the complete updated file in a single code block." — Without this, Copilot gives you fragments. You paste wrong. Everything breaks.
✅ Starting from scratch Build me a [quiz / clicker game / random generator / story / arcade game] about [topic]. It should have [feature 1] and [feature 2]. Use only HTML, CSS, and JavaScript in a single file. Give me the complete updated file in a single code block.
✅ Adding one feature (paste your whole file first) Here is my current index.html: [paste entire file]. Add a [high score tracker / timer / sound effect / difficulty setting]. Do not change anything else. Give me the complete updated file in a single code block.
✅ Fixing a bug My code has this bug: [paste the error OR describe what goes wrong]. Fix it without changing any other functionality. Explain what caused the bug in 2 sentences. Give me the complete updated file in a single code block.
✅ Styling / making it look better Here is my current index.html: [paste entire file]. Add CSS that makes this look like [retro arcade / clean modern / dark mode / cartoon]. Keep all JavaScript working exactly as-is. Give me the complete updated file in a single code block.
🆘 Stuck? Use this I am trying to [goal]. My current code does [behavior]. I want it to [desired behavior] instead. What should I change? Give me the complete updated file in a single code block.

Save Your Work — Commit Every Session
⚠️
Codespaces do not auto-save to GitHub. If you close your browser without committing, your work is in a suspended container — not safe. Commit at the end of every session. Takes 30 seconds.
  1. 1
    Open the Terminal Menu → Terminal → New Terminal. A panel opens at the bottom of the screen.
  2. 2
    Stage your changes Type git add . and press Enter.
  3. 3
    Commit with a real message Type git commit -m "add score tracker and sound" — write what you actually did, not "update."
  4. 4
    Push to GitHub Type git push and press Enter. Your work is now saved on GitHub and will not be lost.
🏆
Good commit messages: "add quiz scoring logic" · "fix mobile layout" · "add timer and high score" · "change to dark mode colors"
Bad: "stuff" · "update" · "idk" · "aaaaaa"
